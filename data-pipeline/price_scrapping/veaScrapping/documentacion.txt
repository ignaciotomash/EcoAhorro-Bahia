# SCRAPER VEA

## 🎯 Descripción
Extrae productos de www.vea.com.ar (Supermercados VEA) usando Playwright + API VTEX. Obtiene EANs del HTML, luego enriquece datos mediante API. Salida: CSV con ID, nombre, marca, presentación, categoría y precio.

---

## ⚙️ Cómo Hace el Código

1. **Inicia Playwright** → Abre un navegador Chromium para renderizar páginas
2. **Itera por categorías** → Para cada una de las 17 categorías de VEA (bebidas, almacén, frutas-verduras, etc.)
3. **Carga página paginada** → Navega a la URL de la categoría esperando que cargue el contenido
4. **Extrae texto HTML** → Obtiene todo el contenido renderizado de la página
5. **Busca EANs con regex** → Aplica el patrón `\b7\d{12}\b` para encontrar todos los códigos de producto
6. **Filtra duplicados** → Compara EANs encontrados contra los ya procesados
7. **Consulta API por cada EAN nuevo** → Envía peticiones paralelas a VTEX para obtener datos completos
8. **Escribe resultados** → Guarda cada producto en CSV mientras se procesan
9. **Avanza a siguiente página** → Repite hasta agotar la categoría
10. **Finaliza** → Cierra navegador y archivo CSV

---

## 🔧 Cómo Funciona

### 1. Navegación con Playwright
- Carga dinámicamente cada categoría (17 en total)
- Renderiza JavaScript para obtener HTML completo
- Espera 4 segundos a que carguen todos los productos

### 2. Extracción de EANs (Regex)
- Busca a través de la expresión regular: `\b7\d{12}\b` que significa "búscame todos los números que empiecen con 7, tengan 13 dígitos y formen una cadena"
- Muy rápido y resistente a cambios de diseño HTML

### 3. Enriquecimiento (API VTEX)
- Consulta: `https://www.vea.com.ar/api/catalog_system/pub/products/search?fq=alternateIds_Ean:{ean}`
- Obtiene: nombre, marca, presentación, categoría, precio
- Paralelo: 50+ peticiones simultáneas (asyncio)

### 4. Persistencia
- Guarda en CSV inmediatamente
- Evita pérdida de datos si falla
